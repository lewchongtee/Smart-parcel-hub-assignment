# Smart Parcel Delivery Hub Management System

Python group assignment for **BER2013 Algorithm Design & Analysis** (UCSI University). The program manages parcels at a delivery hub and compares algorithms on the same data.

## Tasks and owners

| Task | File | Owner |
| --- | --- | --- |
| Task 1: Parcel registration and record management; Task 2: dispatch queue, returns stack, tracking BST | `member_a_task1_task2.py` | Ooi Yan Zhe |
| Task 3: Searching, sorting and recursion (recursive binary search, linear search, merge sort) | `member_b_task3.py` | Lew Chong Tee |
| Task 4: Van loading and delivery optimisation (greedy vs dynamic programming / knapsack) | `member_c_task4.py` | Kuhavengdesh |

`shared_spec.py` defines the parcel record shape and validation used by every module. `Assignment.py` is the main menu-driven program that runs everything and saves the benchmark charts.

## Run

```
pip install matplotlib
python Assignment.py
```

Python 3.11 or newer is recommended.
