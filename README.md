# Smart Parcel Delivery Hub Management System

Python group assignment for **BER2013 Algorithm Design & Analysis** (UCSI University). The program manages parcels at a delivery hub and compares algorithms on the same data.

## Files and owners

| File | Covers | Owner |
| --- | --- | --- |
| `member_a_task1_task2.py` | Task 1: parcel registration and record management. Task 2: dispatch queue, returns stack, tracking BST | Ooi Yan Zhe |
| `member_b_task3.py` | Task 3: searching, sorting and recursion (recursive binary search, linear search, merge sort) | Lew Chong Tee |
| `member_c_task4.py` | Task 4: van loading and delivery optimisation (greedy vs dynamic programming / knapsack) | Kuhavengdesh |
| `Assignment.py` | Main menu-driven program that runs everything and saves the benchmark charts | Teo Li Yuan Jovan (Team Leader) |
| `shared_spec.py` | Parcel record shape and validation used by every module | Teo Li Yuan Jovan (Team Leader) |

## Run

```
pip install matplotlib
python Assignment.py
```

Python 3.11 or newer is recommended.
